# V2 multi-seed experiments

Run the checked-in Chapter 0 experiment with fixed seeds and strategies:

```bash
npm run experiment:v2
```

The command writes aggregate-only `experiment.json`, `experiment.csv`, and `report.md` under
`v2/experiments/output/` (ignored by Git). Re-run with another config or output directory using:

```bash
node scripts/run-v2-experiment.mjs --config v2/experiments/chapter0.json --out-dir /tmp/cammelot-experiment
node scripts/report-v2-experiment.mjs /tmp/cammelot-experiment/experiment.json
```

Each configured strategy runs every listed seed. Strategy patches are restricted to existing
numeric scenario parameters and mechanism fields; scenario validation and canonical hashing still
apply. The runner reports the engine version and scenario hash for each run. Named/indexed
exogenous streams are independent of policy-dependent code, but changing an exogenous parameter
(such as arrival rate) changes its distribution and can change the realized trace. Its default ±20%
sensitivity smoke uses the same five parameter paths already exercised in
`tests/v2/acceptance.test.js`; paired deltas are descriptive and assert no universal direction.

All reports are labelled **synthetic**. They describe only the supplied model scenario, contain no
patient-level records, and are not clinical evidence or claims about Dutch healthcare.

`sample-report.md` is a compact example generated by the checked-in config.
